Portfolio Design System

Layout explorations, the chosen composition, and the tokens and components the site is built from. One rule runs through all of it: whitespace is spent between groups, never inside them. Sections are separated by space first, then marked with a very subtle divider.

Principles

Three ideas decide every layout question on the site.

Dense groups, generous gaps

Related things sit tight together (8–16px). Unrelated things are separated by real air (96px). Density comes from tight groups, calm comes from the gaps between them.

One voice, one weight shift

Hanken Grotesk for everything people read, in two weights: 400 for reading, 500 for naming. The system monospace appears in one place only: the project type tag. Hierarchy comes from size and color (ink vs muted), never from bold, italics or fills.

Space first, then a whisper of line

Every section divider is centered in its gap: content, 80px, a very subtle divider, 80px, the heading, 48px, the content. The divider is decorative and barely there; the space does the separating. Numbers appear only where order is real.

Scroll behavior

Motion helps people orient. It never stages or hides content.

Sticky header

72px (64px on phones), always visible. A subtle divider appears only after the page scrolls 8px, so the top of each page stays clean.

Sticky index with scroll-spy

On case studies from 1024px up, the index sticks 24px below the header. The current chapter (the last one past 30% of the screen) gets a thick indigo bar, indigo text and a pale indigo tint. Below 1024px it hides and chapters stack.

Page switches

Moving between pages (home, a case study, About, CV, a post) never scrolls across content: the new page appears at its position instantly and fades in over 0.28s. No fade for visitors who prefer reduced motion.

Anchored jumps

Every chapter has a deep link (for example #ltp-deliver). Jumps within the same page are smooth (unless the visitor prefers reduced motion) and land 24px below the header.

Remembered position

Opening a case study from home and coming back returns you to where you were in the list.

Everything visible at rest

No scroll-triggered reveals, parallax or scroll-jacking. What loads is what you see. Hover gives small feedback: arrow nudge, underline, 1.5% image zoom.

Lazy media

Images below the first screen load lazily, which keeps long case studies quick on phones.

Type color

  • Headings, body text, the logo and the hand-drawn icons use indigo ink (--fg), never pure black.
  • Labels, captions, leads and dates use the grey-violet --muted.
  • Indigo (--mark) is for interactive or “you are here” marks only, never for body copy.
  • Clay text appears only inside the type tag.
  • The stakeholder logo card is linen with a multiply blend, so the logos sit on the page color in light mode.
  • The favicon uses indigo ink on linen.
  • Screenshots keep their own product colors.

Rules

Quick checks before adding anything new to the site.

Do

  • Group first, then space: decide what belongs together before choosing a gap.
  • Use only spacing tokens; if none fits, the grouping is wrong.
  • Keep text under 64ch, even in wide columns.
  • Pair text with the image that proves it.
  • Keep Work and Writing side by side on the home page, each at its natural height.
  • Number things only when the order is real.

Don’t

  • Use text arrows (→ ↗) or hand-drawn icons in controls; use UI icons. Add a third font weight, italics, or a color outside indigo and clay (no greens or terracotta: those belong to Green Tara). Monospace is reserved for the type tag.
  • Use the 3:1 --line color for section dividers. Dividers use --divider and always sit centered: 80 → line → 80 → heading → 48 → content (56–80 fluid, --half).
  • Use filled cards, shadows, or tinted bands. The Work card is the only outlined box, and it holds a whole project.
  • Animate content in on scroll.
  • Put a label in a left column for every block. It’s for section heads only.
